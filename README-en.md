# MFW-ChainFlow Updater

**[简体中文](./README.md) | [English](./README-en.md)**

## What is this

Standalone updater sidecar for [MFW-ChainFlow Assistant](https://github.com/overflow65537/MFW-PyQt6). After the main program exits, it applies full updates on Windows, Linux, and macOS.

This repository holds the updater source and prebuilt release artifacts. The main app downloads platform binaries from GitHub Releases during assembly, so the updater is not compiled again there.
