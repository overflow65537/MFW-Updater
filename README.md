# MFW-ChainFlow Updater

**[简体中文](./README.md) | [English](./README-en.md)**

</div>

## 这是什么

[MFW-ChainFlow Assistant](https://github.com/overflow65537/MFW-PyQt6) 的外置更新器（sidecar）。主程序退出后，由它独立执行全量更新，支持 Windows、Linux 与 macOS。

本仓库单独维护更新器源码与预编译产物；主程序在组装发行版时从本仓库的 GitHub Release 下载对应平台的二进制，无需重复编译。
